# Frontend Application • Aegis Wealth Terminal

Каталог для исходного кода клиентского приложения.

## Быстрый старт:
Рекомендуется инициализировать проект с помощью Vite:
```bash
npm create vite@latest . -- --template react-ts
npm install
npm install -D tailwindcss postcss autoprefixer
```

Все типы данных и эндпоинты бэкенда описаны в файле: `../docs/FRONTEND_API.md`.
