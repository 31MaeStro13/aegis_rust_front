## 🟢 Сплит 1: Фундамент и Авторизация (Auth & Shell)
**Цель:** Поднять скелет приложения, настроить роутинг и закрыть банковскую авторизацию.

* **Стек:** React (Vite) + TypeScript + Tailwind CSS (компоненты `shadcn/ui` + иконки `lucide-react`).
* **Задачи:**
  1. Инициализация репозитория, настройка алиасов путей (`@/components`), подключение темной темы.
  2. **Экран входа (`/login`):** поля Email / Пароль ➔ отправка на `POST /api/v1/auth/login/`.
  3. **Экран 2FA (`/login/2fa`):** если бэкенд вернул HTTP 200 с флагом `two_factor_required: true` — отображать ввод 6 цифр из приложения-аутентификатора (Яндекс Ключ, 2FAS, Google Authenticator) ➔ отправка на `POST /api/v1/auth/2fa/verify/`.
  4. Сохранение `access_token` в память/куки и настройка Axios/Fetch интерцептора (прикрепление заголовка `Authorization: Bearer <token>` к каждому запросу).
  5. Защищенный роут (`ProtectedRoute`): неавторизованных пользователей перенаправлять на `/login`.
* **Результат сплита:** Рабочий вход по логину/паролю и 2FA коду с переходом в пустой личный кабинет.

## 🟡 Сплит 2: База клиентов (Advisor Dashboard)
**Цель:** Рабочее место советника — управление списком инвесторов и выбор клиентского портфеля.

* **Задачи:**
  1. **Хедер терминала:** логотип Aegis Wealth, имя/статус советника, кнопка выхода.
  2. **Главный экран (`/clients`):** таблица или карточки инвесторов (`GET /api/v1/clients/`).
     * Колонки: ФИО инвестора, объем капитала (AUM), риск-профиль (бейдж: Консервативный / Умеренный / Агрессивный), число счетов.
  3. **Модальное окно «+ Добавить клиента»:** форма с ФИО, телефоном, email, заметками и селектором риск-профиля (`POST /api/v1/clients/`).
  4. Клик по строке клиента ➔ переход в его терминал (`/clients/:id/terminal`).
* **Результат сплита:** Советник видит базу инвесторов, может зарегистрировать нового клиента и перейти в его карточку.

## 🟠 Сплит 3: Терминал портфеля (Portfolio X-Ray Dashboard)
**Цель:** Флагманский двухколоночный экран аналитики (загрузка отчетов и визуализация метрик).

* **Задачи:**
  1. **Левая колонка (Portfolio X-Ray):**
     * Компонент Drag-and-Drop загрузки файла брокера (`.xlsx`, `.csv`) ➔ отправка `multipart/form-data` на `POST /api/v1/portfolio/upload/` (поле формы `file`).
     * Карточки ключевых метрик: Общая стоимость (AUM), Индекс концентрации HHI (со шкалой риска: зеленый `low` / желтый `moderate` / красный `high`), Топ-актив.
     * Donut Chart (библиотека `Recharts`): распределение по классам активов (Акции, Облигации, Фонды, Валюта).
     * Таблица активов (тикер, наименование, доля в %, текущая стоимость).
  2. **Правая колонка (Сценарии и Моделирование):**
     * Кнопка «Стресс-тест (-15%)» ➔ вызов `POST /api/v1/portfolio/simulate/` с параметрами `{"scenario": "stress", "positions": [...]}`.
     * Кнопка «Ребалансировка в ОФЗ» ➔ вызов `POST /api/v1/portfolio/simulate/` с параметрами `{"scenario": "rebalance", "positions": [...]}`.
     * Мгновенное обновление цифр и графиков в левой колонке по результатам ответа симуляции.
* **Результат сплита:** Полноценно функционирующий аналитический дашборд с интерактивным пересчетом сценариев.

## 🔴 Сплит 4: Экспорт PDF и Полировка UI
**Цель:** Финализация готового коммерческого B2B продукта под ключ.

* **Задачи:**
  1. **Акцентная кнопка «Сформировать PDF-отчет для клиента»:**
     * Вызов `POST /api/v1/portfolio/export_pdf/` с массивом `positions` в теле запроса.
     * Индикатор загрузки (спиннер / лоадер «Формирование отчета...»).
     * Автоматическое скачивание полученного Blob-файла с именем `aegis_portfolio_report.pdf` в браузере.
  2. **Система Toast-уведомлений (`sonner` / `react-hot-toast`):**
     * Обработка ошибок: «Файл поврежден или не поддерживается», «Сессия истекла», «Неверный код 2FA».
  3. **Полировка UI:** пустые состояния (Empty States), микроанимации при обновлении метрик, адаптивная верстка под десктопные экраны советников.
* **Результат сплита:** 100% готовый веб-терминал, готовый к демонстрации и внедрению в банки и брокерские компании.
