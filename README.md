# Aegis Wealth Terminal • External Development Hub

Этот репозиторий предназначен для внешней разработки клиентского интерфейса (Frontend) и высокопроизводительного расчётного ядра (Rust Core) терминала инвест-советника **Aegis Wealth**.

Все серверные модули (бэкенд, базы данных, брокерские адаптеры и безопасность) изолированы во внутреннем контуре и взаимодействуют с этим репозиторием по строгим контрактам данных.

## 👨‍💻 Инструкция для Фронтенд-разработчика (Frontend / UI)

1. Ознакомьтесь со спецификацией API: [`docs/FRONTEND_API.md`](docs/FRONTEND_API.md).
2. Рабочий каталог приложения: `frontend/`.
3. Рекомендуемый технологический стек: **React (Vite) + TypeScript + Tailwind CSS / shadcn/ui**.
4. Основные экраны для реализации:
   * **Авторизация & 2FA:** Вход по логину/паролю + ввод 6-значного TOTP-кода.
   * **База клиентов (Advisor Dashboard):** Таблица клиентов советника со сводкой AUM и статусами.
   * **Модальное окно создания клиента:** ФИО, контакты, выбор риск-профиля (консервативный, умеренный, агрессивный).
   * **Терминал портфеля:** Загрузка отчёта (Excel/CSV), отображение структуры портфеля (акции/облигации/деньги), индекс концентрации HHI.
   * **Стресс-тест & Ребалансировка:** Слайдер падения рынка (-15%), симуляция перевода части средств в ОФЗ под ставку ЦБ РФ.
   * **Экспорт отчёта:** Кнопка скачивания PDF для клиента.

## 🦀 Инструкция для Rust-разработчика (Rust / PyO3 Engine)

1. Ознакомьтесь с подробным ТЗ: [`docs/RUST_CORE_SPEC.md`](docs/RUST_CORE_SPEC.md) (или Word-версией [`docs/RUST_CORE_SPEC.docx`](docs/RUST_CORE_SPEC.docx)).
2. Исходный код ядра размещается в `crates/aegis_core/`.
3. Требуется реализовать 5 базовых функций:
   * `calculate_hhi` — Индекс концентрации Херфиндаля-Хиршмана.
   * `calculate_allocation` — Доли классов активов (акции, облигации, фонды, кэш).
   * `simulate_stress` — Моделирование рыночной просадки.
   * `simulate_rebalance` — Моделирование перетока капитала в ОФЗ-флоатеры под ставку ЦБ.
   * `calculate_risk_metrics` — Коэффициент Шарпа, годовая волатильность, Max Drawdown.
4. **Тестирование обязательно:** Покрытие unit-тестами `cargo test` не менее 90% (включая граничные случаи: 1 акция, 100% бонды, пустые портфели без паник).
5. Сборка модуля Python: через `maturin develop`.
